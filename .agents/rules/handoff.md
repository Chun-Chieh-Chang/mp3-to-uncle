# Handoff 規則 (用量接近上限時交接)

當 session、weekly 或 overall 任一可用額度**用到 97.5%** 時，必須立刻停止新工作，先更新專案根目錄的 `handoff.md`，再繼續。

## handoff.md 必須包含
1. **目標**：使用者原始需求與已確認的決策。
2. **目前進度**：已完成項目、已驗證項目（附證據），以及尚未驗證項目。
3. **待辦清單**：依優先順序列出下一步，第一項必須能直接開始執行。
4. **已知問題與根因**：包含失敗嘗試，避免下個 session 重複踩坑。
5. **環境與指令**：測試連結、啟動指令、相依套件。
6. **未提交變更**：`git status` 摘要。聲明是否已取得 push 許可。

## 限制
- 我只能看到自己的 context，無法直接讀取帳號額度百分比。若平台未提供用量數值，則以使用者告知或平台提示為準。
- 這與既有的「token 剩 20% 時記錄進度」規則並存。兩者都要遵守，以先到者為準。
